# Orientação DDM — Expo

Projeto baseado no PDF de orientação: Login, Home, navegação com React Navigation e estilos separados.

## Executar

1. Instale o Node.js.
2. Abra esta pasta no VS Code e abra o terminal.
3. Execute `npm install`.
4. Execute `npm run web` para abrir no navegador ou `npm start` para usar o Expo Go.

**Observação:** O botão Entrar navega diretamente para a Home, conforme o exercício. Não há autenticação real nem banco de dados.
